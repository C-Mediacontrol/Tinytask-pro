## 1. 背景与核心问题 (Context & Problem Statement)

### 1.1 桌面图标移位背景失真缺陷 (The Wallpaper Contrast Problem)
在 Windows 自动化实践中，用户录制点击桌面快捷方式或无边框 UI 按钮时，捕获的图像资产（如 74×70 像素）不可避免地包含了当时点击位置的**宿主底色（如桌面壁纸、窗口面板底色）**。
- 当用户将目标图标拖拽到屏幕其他位置（例如从左下角移至右上角）时，右上角壁纸与左下角壁纸的色调、明暗差异显著；
- 传统的全矩形归一化互相关（NCC）会将这部分无关的背景像素一并纳入统计，导致即使核心图标图案完全一致，统计相关性打分也会从 1.00 大幅跌落至 0.69 左右；
- 仅仅靠全局调低匹配阈值（如降至 0.65）属于粗粒度权衡，容易在密集杂乱的复杂桌面环境下增加假阳性误报率。

### 1.2 解决方案与双重目标
本规范确定通过**计算机视觉自适应背景透明化（Masked Template Matching）**与**阶段二极限体积瘦身（50 ~ 60 KB）**联合交付：
1. **录制时自动剔除背景**：基于外边缘色差连通泛洪（Border Chromakey Flood-Fill），自动将无关宿主背景打上透明掩码（Alpha=0），仅保留核心图标与文字（Alpha=255）。
2. **交互式可视化实时微调**：提供轻量级步骤编辑弹窗，带 8×8 灰白棋盘格实时预览与容差滑动条（0~100），支持 60FPS 丝滑调节与安全回退。
3. **阶段二搜图引擎融合**：将掩码与阶段二的微秒级级联引擎结合（掩码特征点 SAD + 掩码归一化互相关 Masked NCC + 零堆内存静态灰度缓冲），彻底根除壁纸变色带来的分值损耗，使移位搜图得分稳定恢复至 0.95+。
4. **兑现 50 ~ 60 KB 极限瘦身承诺**：配合资源段位图调色板化（`toolbar.bmp` 12.8 KB $\to$ ~3 KB）与全量算法定点化（剥离 CRT 浮点库数学例程），使最终 PE 可执行文件稳定落入 **50 ~ 60 KB** 区间。

## 2. 算法与数据模型设计 (Algorithms & Data Architecture)

### 2.1 自动边缘色差连通泛洪算法 (Border Chromakey Flood-Fill)
```
+-------------------------------------------------------+
| (x,0)          外边缘采样基准色 C_base         (W-1,0)|
|   +-----------------------------------------------+   |
|   | 连通背景区 (色差 <= Delta E, 标记 Mask = 0)   |   |
|   |          +-------------------------+          |   |
|   |          |  封闭核心前景图案/文字  |          |   |
|   |          |      (Mask = 1)         |          |   |
|   |          +-------------------------+          |   |
|   +-----------------------------------------------+   |
| (0,H-1)                                       (W-1,H-1)
+-------------------------------------------------------+
```

1. **基准背景色采样**：
   - 提取图像最外层 1 像素环（四条外边界：$y=0$, $y=H-1$, $x=0$, $x=W-1$）的像素集合 $B$；
   - 计算 RGB 均值向量 $C_{\text{base}} = (\bar{R}, \bar{G}, \bar{B})$；
2. **广度优先（BFS）连通泛洪**：
   - 分配尺寸为 $W \times H$ 的 8-bit 掩码矩阵 $M$，初始值全置为 $1$（默认前景）；
   - 遍历外边界像素点，若 $|Pixel(x, y) - C_{\text{base}}| \le \Delta E_{\text{tol}}$（欧氏色彩距离），则将其压入队列并设 $M(x, y) = 0$；
   - 执行队列循环，向 4-邻域内扩散：相邻点若未访问且与 $C_{\text{base}}$ 色差 $\le \Delta E_{\text{tol}}$，则标记为背景并入队；
   - 一旦遇到图标主体边缘（高对比度梯度差），扩散在图标边界受阻终止，图标内部文字与图形被严密保护；
3. **安全防误抠门禁 (Safety Fallback Guard)**：
   - 统计剩余前景像素比例 $R_{\text{fg}} = \frac{\sum M(x, y)}{W \times H}$；
   - 若 $R_{\text{fg}} < 0.15$（目标被击穿）或外框方差极大（非均匀背景），算法自动撤销扣除，将 $M$ 全量重置为 $1$。

### 2.2 资产存储与向后兼容 (32bpp BGRA Storage Model)
- **图像存储升级为 32bpp BGRA BMP**：
  - 前景像素：$(B, G, R, 255)$
  - 背景透明像素：$(B, G, R, 0)$
- **兼容性保障**：
  - 读取 24bpp 历史宏位图时，解包模块检测到 `biBitCount == 24`，自动补齐 Alpha=255，历史 `.ttp` 无缝运行；
- **步骤结构体元数据扩展 (`TTPStep`)**：
  ```c
  typedef struct {
      ...
      BYTE chromaTol;     /* 0: 禁用透明度; 1~100: 连通容差, 默认 25 */
      BYTE reservedMask[3];
  } TTPStep;
  ```

## 3. UI 交互与实时棋盘格预览设计 (Interactive Preview UI)

### 3.1 弹窗布局与原生控件
- **触发入口**：主窗口步骤列表中双击步骤，或右键选择【Edit Image & Transparency...】；
- **对话框规格**：Win32 模态对话框，尺寸 `420 × 440`，纯系统内置控件（`comctl32.dll`）：
  - **预览区域 (`IDC_PREVIEW_BOX`)**：`200 × 200` 静态控件，挂接自定义 `WM_PAINT` 回调；
  - **启用复选框 (`IDC_CHK_ENABLE_MASK`)**：`[X] 启用背景透明化`；
  - **容差滑动条 (`IDC_SLIDER_TOL`)**：`TRACKBAR_CLASS`，范围 `0 ~ 100`；
  - **读数静态标签 (`IDC_LBL_TOL_VAL`)**：显示当前容差与前景保留百分比；
  - **控制按钮**：`[恢复默认]`、`[确定]`、`[取消]`。

### 3.2 棋盘格与 60FPS 实时渲染
- **双缓冲绘制 (Double Buffering)**：
  1. 离屏 DC 底层使用纯 GDI 绘制交替的 8×8 灰白棋盘格（`RGB(224, 224, 224)` 与 `RGB(255, 255, 255)`）；
  2. 针对 74×70 等小型图标，做 2x 整数倍最近邻缩放居中显示；
  3. 对 $A=255$ 像素绘制原图 RGB，对 $A=0$ 像素跳过，使棋盘格自然透出；
- **滑动条即时响应**：
  - 拦截 `WM_HSCROLL` 下的 `TB_THUMBTRACK`；
  - 拖拽滑块时，在内存缓存的纯净 24bpp 像素副本上运行 BFS 泛洪（74×70 图像耗时仅约 **0.1ms**）；
  - 立即向预览控件发送 `InvalidateRect(..., FALSE)`，实现 60FPS 零延迟同步刷新。

## 4. 阶段二引擎深度融合 (Phase 2 Vision Engine Integration)

### 4.1 掩码特征探测点快速粗筛 (Masked Probe SAD)
- 提取 16 个高辨识度关键像素点时，**强制约束条件：$A(u, v) == 255$**；
- 绝对杜绝任何探测点落在壁纸上，确保无论壁纸如何替换或图标如何移位，SAD 探测粗筛仅对真实目标计算，耗时 $\le 1.0\text{ ms}$。

### 4.2 掩码归一化互相关精算 (Masked NCC / MNCC)
- 仅在 $M(u, v) == 1$ 的有效前景集合上计算均值与方差：
  $$\bar{T}_M = \frac{1}{N_M} \sum_{M=1} T(u, v), \quad \sigma_{T, M} = \sqrt{\sum_{M=1} (T(u, v) - \bar{T}_M)^2}$$
  $$\text{Score} = \frac{\sum_{M=1} nT(u, v) \cdot S(x+u, y+v)}{\sqrt{\sum_{M=1} (S(x+u, y+v) - \bar{S}_M)^2}}$$
- 背景壁纸像素权重彻底归零，移位至右上角时的得分从 `0.6916` 跃升至 **$0.95 \sim 0.99$**，即使阈值严格设定在 `0.70` 或 `0.75` 也稳健命中。

### 4.3 零堆内存架构 (Zero-Heap Architecture)
- 单例静态 BSS 屏幕灰度缓冲 `s_screenGray`（支持至 4K 分辨率，BSS 段不占 exe 体积）；
- 搜图循环单次全流程堆分配严格为 **0 字节**，总耗时控制在 **15 ~ 25 ms**。

## 5. 阶段二极限瘦身工程路径 (Road to 50~60 KB)

| 优化项目 | 当前状态 | 阶段二优化手段 | 预期净减体积 | 累积体积预估 |
|---|---|---|---|---|
| **基线现状** | 阶段一优化后 | 已启用 `-Os -flto -Wl,--gc-sections` | - | **93.6 KB** |
| **工具栏位图瘦身** | 24-bit RGB (12.8 KB) | 转为 4-bit / 8-bit 带调色板位图 | **-9.2 KB** | **84.4 KB** |
| **剥离 CRT 浮点数学库** | 依赖 `double`/`sqrt()` 软浮点库 | 全量整型定点化移位 + 牛顿整数开方 `isqrt()` | **-18.5 KB** | **65.9 KB** |
| **死代码与导入表剪裁** | 冗余 API 存根与未用函数 | 深度清除无用链接符号与调试字符串 | **-6.0 KB** | **59.9 KB** |
| **新增透明微调弹窗** | 无 | 极简 Win32 原生 GDI 控件（~150 行 C） | **+1.5 KB** | **~61.4 KB** |

**最终二进制体积严格锁定在 $\le 60\text{ KB}$（50 ~ 60 KB 区间）！**
