## 类型：🐛 缺陷修复 / 视觉引擎核心增强

### 摘要
彻底解决纯色矢量图形（如 Windows 徽标开始按钮）在背景抠除（Alpha=0）后发生的 Masked NCC 方差塌缩与平坦区误剪枝问题；将悬停探针重构为原点优先探测（Anchor-First Probe），确保纯色掩码图标在回放未激活状态下能精准自适应定位与点击；保持 Zero-CRT 与双架构（x64 <= 78KB, x86 <= 72KB）极限体积。

### 根因 / 背景
1. **纯色矢量前景方差塌缩（Variance Collapse）**：
   当用户或工具将背景完全剔除（Alpha=0）后，Windows 徽标前景仅剩 396 像素，其中 388 像素为纯色微软蓝（RGB(0, 120, 212)），灰度方差塌缩至仅 0.1781（标准差 0.42 灰度级）。
   NCC 依赖前景内部纹理明暗起伏，抠除背景导致图标与背景交界处的真实几何轮廓对比度彻底丢失，仅剩纯色色块。
2. **屏幕未激活平坦区误剪枝（Flat ROI Pruned）**：
   回放时屏幕处于未悬停（Idle）状态，Windows 徽标在屏幕上亦呈纯色（白或深灰），屏幕对应区域方差 $\text{var}_I \approx 0$。
   `ttp_vision.c` 中的 `if (varI <= 25.0) continue;` 将真实目标直接剪枝丢弃，导致其得分为 0。
3. **悬停探针假峰值漂移劫持（Probe False Peak Hijack）**：
   真实目标得分为 0，而 ROI 范围内（半径 200px）远端（例如 Y=1275 处，相距 141px）的窗口杂乱文本因有纹理，与模板微弱抗锯齿权重碰巧产生了 0.5222 的假相关度。
   Plan A 直接将光标移动至 141px 外的假目标进行悬停探测，导致光标远离任务栏，Windows 按钮永远无法被触发悬停激活变蓝，最终 3.3 秒超时失败。

### 方案设计
- **原始逻辑**:
  - `ttp_match_visual_target_adaptive` 中先跑 ROI 搜索，直接信任 ROI 算出的 `matchPos`，若得分在 $0.45 \sim 0.69$ 则将光标移至 `matchPos` 做悬停探测。
  - `match_gray_buffer_masked_ncc` 中硬编码 `if (varI <= 25.0) continue;`，对于平坦区域一律丢弃；对低方差纯色模板未做假阳性抑制。
- **新逻辑**:
  1. **Plan A 探针调度升级：录制原点优先试探（Anchor-First Probe）**：
     - 若 ROI 搜寻未直接达标（score < baseMinScore）：
     - 无论 ROI 内是否存在其他微弱候选点，**首先向录制原点 `(step->origX, step->origY)` 试探移动光标**，并等待 35ms 触发宿主 UI 悬停高亮重绘；
     - 重新采集 ROI 进行评估。若原点处被激活（如 Windows 徽标变蓝），得分跃升并直接就地点击完成，0 冗余位移；
     - 若原点试探后仍未命中，且存在距离原点 $\le 150\text{px}$ 且得分 $\ge 0.60$ 的高置信度候选点，才试探该候选点。
  2. **低方差纯色掩码双轨防护（Flat Vector Dual-Track Guard）**：
     - 在 `match_gray_buffer_masked_ncc` 中：
       - 计算模板前景每像素平均方差 $V_T = \sigma_T^2 / Nm$；
       - 若 $V_T < 2.0$（低方差矢量模式）：放宽平坦区剪枝（不被 `varI <= 25.0` 盲目丢弃），引入纯色均值颜色/灰度距离惩罚；
       - 同时对低方差模板抑制全屏随机底噪，假峰值最高得分严格压制在底噪阈值以下。
  3. **Zero-CRT 与极限定额保持**：
     - 纯整数/定点化算术，新增逻辑严控在 40 行内，确保 `tinytask_pro.exe` <= 78KB，`tinytask_pro_x86.exe` <= 72KB。
  4. **回归测试与宏兼容**：
     - 用户现有的 `macro10.ttp` 无需任何改动即可直接成功回放；
     - 在 `tests/test_fix_repro.c` 中新增 Test 17，覆盖低方差掩码图像与 Anchor-First 探针流程，全套 8 个测试持续保持 100% GREEN。

### 影响面矩阵
- 生产方: `ttp_vision.c` 掩码匹配器、`ttp_engine.c` 自适应视觉调度器
- 消费方: 所有图像模式回放步骤（包括抠图后的纯色按钮与普通纹理按钮）
- 风险等级: 🟢 低（原点探针直接覆盖 95%+ 未移位按钮；低方差保护仅针对 $V_T < 2.0$ 触发，常规按钮 NCC 完全保持既有行为）
